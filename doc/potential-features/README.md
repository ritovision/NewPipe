# Potential Features

This folder holds **deferred and exploratory proposals** for the personal NewPipe fork. Documents here are not commitments to implement, and should contain alternatives, risks, and open decisions.

- [Pruning — Library Health and AI-Assisted Repair](pruning-library-health.md) — low-priority concept: scan for unavailable streams, optionally bulk remove them, export a report for AI, or propose approved replacements.
- [Library Playlist System](../specs/library-playlist-system.md) — agreed higher-priority product semantics, documented separately under specs.

Prefer moving an idea into an agreed specification only after scope and acceptance criteria are settled. No implementation is implied by adding an idea here.
